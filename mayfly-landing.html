A few things, answered

Before your first preview.

What is an ephemeral environment?

It is a temporary deployment created for a specific change, usually a pull request. It gives reviewers an isolated place to test and has a defined end to its lifetime.

Does Mayfly replace my CI pipeline?

This concept places Mayfly around your existing build and deployment workflow. The first proposed version targets one repository and one deployment platform. Provider integrations still need implementation.

What happens when a pull request closes?

The proposed workflow starts teardown when a pull request merges or closes. An expiry policy provides an additional cleanup trigger for abandoned previews, with failed deletion attempts surfaced for attention.

Is this a working product?

This is an interactive landing page concept. The dashboard uses sample environments and simulated interactions. It does not connect to repositories or provision cloud resources.
